``` python hl:20,23-24
class Attention(torch.nn.Module):
    def __init__(
        self,
        embed_dim,
        num_heads,
        dropout=0.0,
        bias=True,
        use_qk_norm=False,
        norm_layer=nn.LayerNorm,
        headwise_attn_output_gate=False,
        elementwise_attn_output_gate=False,
        device=None,
        dtype=None,
    ) -> None:
        factory_kwargs = {"device": device, "dtype": dtype}
        super().__init__()
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.dropout = dropout
        self.head_dim = embed_dim // num_heads
        assert self.head_dim * num_heads == self.embed_dim, "embed_dim must be divisible by num_heads"

        self.in_proj = torch.nn.Linear(embed_dim, 3 * embed_dim, bias=bias, **factory_kwargs)
        self.out_proj = torch.nn.Linear(embed_dim, embed_dim, bias=bias, **factory_kwargs)

        if use_qk_norm:
            self.q_norm = norm_layer(self.head_dim)
            self.k_norm = norm_layer(self.head_dim)
        else:
            self.q_norm = self.k_norm = nn.Identity()
```

#### in_proj
Linearly projects the embedded representations into smaller sub-spaces, defined by the number of attention heads, 

This allows for faster computation as each attention head can be processed in parallel

Each attention head can also learn different structures/representations (eg one could learn the importance of kaons while another learns larger jet structure)

#### out_proj
Does the same but projecting back up dimensions
